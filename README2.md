Date: 26/03/2026 <br />
Brief Description: <br />
This repository demonstrates the use of several data science models on different datasets sourced from Kaggle and the UCI Machine Learning Repository. They are written in Python using Jupyter Notebook and attempt to draw meaningful conclusions from model results. The first two notebooks investigate the effectiveness of K-Nearest Neighbours regression and classification models for predicting stock market movements a week in advance. The next notebook uses a Convolutional Neural Network to try and predict the species of a butterfly given its image. The next notebook uses both linear and non-linear Support Vector Machine models to try and predict if a particular sonar response is a rock or an sea mine. The next notebook uses a Long Short Term Memory Recurrent Neural Network to try and predict the future energy consumption of a house and includes evaluation of the model and tuning. The final notebook uses Fuzzy C-Means and K-Medoids to cluster wheat seeds into three classes, it also compares the performance of both models and evaluates their suitability for this specific task. <br />
